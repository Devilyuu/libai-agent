# 和李白聊一聊 · 网页人物智能体

《望庐山瀑布》（统编版语文二年级上册）课堂用的 AI 人物智能体：李白站在画面里回答小朋友的提问，会开口说话。
打开网址就能用，学生不用注册登录；可以用 PowerPoint 的 Web Viewer 加载项嵌进 PPT。

在线地址：https://devilyuu.github.io/libai-agent/

## 老师第一次使用

点右上角 ⚙，填一次钥匙（只存在你这台电脑的浏览器里，网页文件里没有）：

- 大模型：火山方舟（豆包）、DeepSeek、通义千问或任意 OpenAI 兼容接口的 API Key
- 声音（可选）：火山引擎豆包语音合成 2.0 的 API Key

## 换一个人物

改 `agent.js`：名字、开场白、快捷提问、人设、音色、立绘路径。立绘是同一姿势的三张透明底图（闭嘴 / 张嘴 / 闭眼），放在 `img/`。
